# NewTech System 🚀
> **نظام إدارة المبيعات والمشتريات والمقاصة المركزية (ERP Accounting & Clearing Ledger)**

---

## 📋 نبذة عن النظام المطور

نظام ويب متكامل لإدارة وتتبع العمليات المالية والمحاسبية بين **NewTech System** وشركات وموردي المول.  
يقوم النظام بمنع العجز المالي بالكامل، ويوفر آلية **مقاصة وتصفية فورية ثنائية** بين ما لك وما عليك، مع دعم التخزين السحابي المركزي عبر **PostgreSQL** والتشغيل المحلي بدون إنترنت عبر **SQLite / IndexedDB**.

---

## ✨ المميزات الرئيسية للنظام

### 1. 🏢 حسابات الشركات والموردين
* إدارة كاملة لشركات المول والموردين الخارجيين مع تحديد نوع الكيان (شركة مسحوبات / مورد مشتريات / شركة ومورد معاً).
* تسجيل دقيق لكافة المسحوبات، فواتير المشتريات، المدفوعات، والمرتجعات.

### 2. ⚖️ التصفية والمقاصة التلقائية بين الحسابات (Automatic Netting)
* حساب فوري للصافي المتبادل بينك وبين كل شركة أو مورد:
  * **المبلغ الذي لي عند الشركة** (مسحوبات مطلوبة).
  * **المبلغ الذي عليّ للشركة** (فواتير مشتريات مستحقة).
  * **الصافي النهائي بعد إجراء المقاصة**:
    * 🔴 **إذا كان لك مبلغ عند الشركة**: يظهر الرصيد المتبقي بـ **اللون الأحمر** الواضح.
    * 🟢 **إذا كان عليك مبلغ للشركة**: يظهر الرصيد المتبقي بـ **اللون الأخضر** الواضح.
    * ⚪ **إذا كان الرصيد متساوياً**: يظهر الحساب متوازناً (0.00 ج.م).
* تحديث الرصيد تلقائياً مع كل فاتورة، حركة دفع، أو مرتجع.

### 3. 📦 فواتير المشتريات من الشركات والموردين
* إنشاء فواتير مشتريات غير محدودة البنود مع:
  * اسم المورد / الشركة، تاريخ الفاتورة، ورقم الفاتورة.
  * جدول بنود ديناميكي: (اسم الصنف، الكود، الكمية، سعر الوحدة، الخصم، السعر النهائي).
  * حساب فوري للإجمالي، الخصومات، الصافي، المدفوع، والمتبقي.
  * ربط الفاتورة تلقائياً بحساب المورد وتحديث المقاصة فور الحفظ.

### 4. 🔄 زر "مرتجع" بجانب زر "تم الدفع"
* زر **مرتجع** مخصص في كل صف بجانب زر "تم الدفع".
* عند تحديد الصنف كمرتجع، يتحول السعر والمبلغ إلى **اللون الأصفر الفوسفوري** لتمييزه فوراً.
* لا يتم احتساب الصنف المرتجع ضمن الديون أو العجز، ويتم تحديث المخزون وحساب المقاصة فوراً.

### 5. 🔐 نظام تسجيل الدخول والمزامنة بين الأجهزة
* شاشة تسجيل دخول تضم خياري: **تسجيل الدخول** و **إنشاء حساب جديد**.
* ربط كافة البيانات (فواتير، شركات، موردين، مسحوبات، مرتجعات) بحساب المستخدم.
* عند تسجيل الدخول بنفس الحساب من أي جهاز، تظهر كافة البيانات الخاصة بالحساب تلقائياً.

### 6. 🗄️ بنية قواعد البيانات (PostgreSQL + SQLite)
* **PostgreSQL (`schema_postgresql.sql`)**: قاعدة البيانات المركزية السحابية (متوافقة مع Supabase / Neon / AWS RDS).
* **SQLite (`schema_sqlite.sql`)**: قاعدة البيانات المحلية للتشغيل المستقل والوضع Offline بدون إنترنت.
* دعم التصدير المباشر لملفات `.sql` لكل من PostgreSQL و SQLite بنقرة واحدة من واجهة النظام.

## 🚀 تشغيل النظام

افتح ملف `index.html` في أي متصفح حديث:
* الحساب الافتراضي: اسم المستخدم: `admin` | كلمة المرور: `1`
* أو انقر على **"إنشاء حساب جديد"** لتسجيل حسابك الخاص فوراً.
